# OSS公開・申請準備の実行計画

## Goal

`dev-standard-kit` を第三者が利用・改善しやすくし、Codex for Open Source の申請時に確認できる根拠を整える。

## Scope

- ライセンスの明示
- READMEの導入手順
- 貢献・Issue・PR・リリースの保守導線
- 利用実績と改善の記録方法

## Out of scope

- 外部サービスへの申請送信
- 数字や採用実績の創作
- Fork先の機密情報の公開

## Dependencies and tasks

| Task | 内容 | 依存 | 受入条件 | 状態 |
| --- | --- | --- | --- | --- |
| 1 | MITライセンスの標準文面とREADMEの案内を追加 | 権利者によるライセンス選択（MITを選択済み） | 標準本文と案内を追加し、公開後にGitHubの認識を確認できる | 完了・レビュー待ち |
| 2 | READMEに初回利用手順を追加 | 既存の起動・検証コマンド | Forkからローカル起動と完全検証までたどれる | 完了・レビュー待ち |
| 3 | 貢献・Issue・PR・リリースの導線を追加 | Task 1 | 外部貢献者が提案・検証・レビュー手順を把握できる | 完了・レビュー待ち |
| 4 | 実績の記録場所と更新ルールを追加 | Task 2、3 | 検証可能な公開URL付きで実績と改善を記録できる | 完了・レビュー待ち |

レビュー済みの小タスクを一つずつ実行し、結果と検証を報告して止まる。次のタスクは同じ作業の延長として開始しない。

## Verification

- READMEのコマンドを既存のscriptsと照合する。
- `npm run harness:verify` を実行し、exit codeと検証内容を記録する。
- Hookが実際に起動したか確認する。起動していなければ手動検証として記録する。

## Risks

- ライセンスは権利者がMITを選択済み。著作権表示は2026年のリポジトリ履歴と所有者名に基づく。
- 実践先はGitHubのForkとして紐づいていない。同じ所有者による公開利用例として扱い、GitHub Fork数や外部利用者数に含めない。
