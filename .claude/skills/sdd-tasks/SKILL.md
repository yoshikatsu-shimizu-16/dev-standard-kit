このスキルの実体は `.agents/skills/sdd-tasks/SKILL.md` にある(Agent Skills open
standardの実装場所を`.claude/skills/`(Claude Code)と`.agents/skills/`(Codex CLI等)の
両方に置き、単一の内容を重複させないための転送ファイル)。

起動したら必ず `.agents/skills/sdd-tasks/SKILL.md` を読み、そこに書かれた
Output / Inputs / Steps / Stop condition / Boundary に従うこと。
